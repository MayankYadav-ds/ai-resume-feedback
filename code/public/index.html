    1 FINAL PROMPT

    Private AI, without an API key

    Run SmolLM2 on your device. First use downloads model files (hundreds of MB) and requires a WebGPU-capable desktop browser. Model files may be cached; resume text stays on your device. This small model can make mistakes; all feedback is checked.

    Connect Gemini (optional)

    Use your own key. It stays in this tab, is sent only to Google, and is never saved. Requests use your Google quota and billing. A configured local server can keep the key server-side instead.

    No provider is connected. Prompt export and manual import work without a key.

    CHECK BEFORE YOU KEEP

    Your AI feedback

    ✧

    Paste the JSON returned by the final prompt, or generate it with a connected provider. Manual responses are not automatically attributed to a model.

    What do these checks prove?

    They check JSON structure, exact source quotations and unsupported numbers. They cannot prove a rewritten claim is truthful or detect every invented skill. Read every suggestion before using it.
